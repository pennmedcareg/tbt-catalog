📋 To add a new presentation:
1. Upload slides to SharePoint CORP Cancer Registry > Documents > Webinars & Conferences
2. Copy the share link for the slides file
3. Click + Add Presentation → fill in title, date, presenter, source, and slides link
4. Add topics using the Import Topics box (Category | Description format)
5. Click ⬇ Import Topics then Save
6. Click ⬇ Export & Save → upload new file to GitHub
